The heading miss came from checking the title and prose without measuring the body heading hierarchy. AGENTS.md now explicitly requires H1–H6, nested content, paragraphs, lists and source checks at desktop/mobile sizes and 100%/90% browser zoom for typography changes. The browser verification script provides those assertions against an isolated test installation.
