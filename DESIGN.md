# Cilo design

Operate mode. The workspace recedes behind the writing.

Use neutral surfaces, crisp one-pixel borders, compact navigation, and generous prose spacing. No decorative gradients, illustrations, dashboard cards, or marketing hero. Desktop has a 216px navigation rail, 300px note list, and a fluid editor with a 740px writing measure. Tablet collapses the rail; mobile shows the list or editor with an explicit back action.

Tokens: white/light background, near-black text; inverse dark surfaces. Muted text must remain legible. Radius 8px for controls, 12px for panels. System sans for interface and prose; monospace only for source and code. UI type 12–14px; editor prose 16px/1.7; title 32px. Focus uses a clear two-pixel neutral ring. Motion is short and functional and respects reduced motion.

Typography, space, and selection carry the identity. Primary actions invert foreground/background. Icons use Lucide with consistent stroke. Empty and error states name the next action. Onboarding is a focused form with a visible step indicator and recovery download.
