# Nivra website

A minimal product introduction for people considering a single-owner, self-hosted workspace. Help visitors understand Nivra through real demonstrations and reach the Docker quick start or application repository.

The product is Nivra; its tagline is “Your thoughts, together.” Notes, journals, tasks, bookmarks, artifacts, Calendar, Kanban, Forms and MCP are implemented in the independent `main` branch. This branch contains only the static marketing website. There is no hosted signup, team collaboration, offline editing or built-in AI chatbot. Encryption is server-side at rest, not end-to-end encryption. Do not invent adoption, testimonials, performance numbers or native applications.

Use the existing monochrome Nivra identity. Linear and Polar inform the calm typography, product scale and restrained information density. Both light and dark themes must work; default to the device preference. Screenshots must show real Nivra UI with authored demonstration data, clearly identified as examples. Never publish private addresses, credentials, account identity or personal content.
